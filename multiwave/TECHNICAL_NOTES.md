# 多波长仿真的技术设计与边界

## 1. 首版研究问题与适用条件

在探针、波长、光谱权重和扫描坐标已知时，共同 OPD 参数化能否改善多波长混合强度反演？给予像素优化相同物理约束后，U-Net 是否仍提供额外收益？首版隔离物体参数化的作用，尚未实现盲探针、未知权重或真实实验数据导入。

薄样品、标量传播、各波长在相机曝光时间内非相干叠加时：

```text
A_l = exp(-tau_l), tau_l >= 0
O_l = A_l * exp(i * 2*pi*d/lambda_l)
I_j = sum_l w_l * |D_l(P_l * S_j(O_l))|^2
```

tau 是振幅光学厚度，不是强度光学厚度。材料模型给出 d=(n-n_background)*h、tau=2*pi*kappa*h/lambda，其中 kappa 是消光系数。共同 d 隐含折射率差在所选波长上近似不变；允许独立吸收不意味着任意材料都满足共同 d。合成样品是离散波长上的现象学模型，未对应某种实测材料，也未验证全谱色散关系。

配置波长单位 nm、像素 um、距离 mm；传播内部统一为 m；网络 OPD 输出为 um。OPD 采用无界线性输出，不把厚度压到有限相位范围。但首版真值 OPD 较小，不能验证大光程差解缠绕能力。

- `coupled`：L 张独立 tau、1 张共同 d。
- `independent`：L 张独立 tau、L 张独立有效 d_l；每通道相位为 2*pi*d_l/lambda_l。
- `common`：1 张 tau、1 张共同相位，直接共享复物体；仅为旧假设消融，不能代表一般非色散样品。

明显色散需要新的模型。完全自由的相位残差可能吸收全部共同 OPD，不能仅凭添加残差就声称保留物理约束。后续可探索已知材料色散基底下的少量厚度图，先检查波长数量、谱差异和可辨识性。本版只提供色散真值压力测试，尚无材料分解求解器。

## 2. 统一网格与角谱传播

选择物面和探测器同采样间隔的近场几何，不套用单 FFT Fresnel 的变采样约束。各波长强度映射到同一探测器像素后才相加。

去除不可观测的全局传播相位后，传递函数为：

```text
q = lambda^2 * (fx^2 + fy^2)
phase = -2*pi*z/lambda * q/(sqrt(1-q)+1)
H = exp(i*phase)
```

它等价于 exp(i*z*(kz-k))，避免 sqrt(1-q)-1 的相消。以 float64 构造传递函数，再转 complex64；物体到数据损失的计算保留 autograd。

物体裁片乘探针 → 中心零填充 → FFT → 乘该波长 H → IFFT → 裁取中心探测器窗口。探针在裁片边缘平滑降为零，因此不截掉有照明的外部样品。

由频率采样的局部相位变化不超过 pi，使用两轴限制：

```text
|z*lambda*fx/sqrt(1-q)| <= FFT_window_x/2
|z*lambda*fy/sqrt(1-q)| <= FFT_window_y/2
```

仅保留传播波；默认采样远大于波长，不以倏逝波为目标。这是受带限角谱文献启发、由采样条件推导的实现，不是对某篇论文全部数值细节的复现。

每次运行把 padding 倍数加倍，比较同一真值的预测强度；相对差超过 1% 时打印提示。窗口稳定不等于物面分辨率充分：后续仍需采样加密验证。当前探测器按离散网格取样，未显式积分像素面积，也未模拟饱和、背景、读出噪声。生成和反演使用同一传播器，属于模型匹配仿真。

## 3. 固定权重与光子预算

样品面探针由平滑有限孔径与共同 OPD 相位屏构造，每模式 sum(|P_l|^2)=1。w_l 是固定有效入射光子比例，和为 1。真实实验需明确光功率到光子数、量子效率的换算，不能直接用任意光功率比例代替 w。

```text
counts_j ~ Poisson(N_in * I_j)
y_j = counts_j/N_in
```

各位置同一个 N_in，不逐帧归一化，不按迭代阶段改变权重。吸收和有限探测窗口使检测光子数低于入射数。`photons_per_scan=0` 表示无噪声。

固定已知探针与曝光标度后，不使用 VarPro 全局幅值拟合。各波长全局相位仍不可观测，共同 OPD 存在整体常数偏置。已知权重和探针不保证多波长反演唯一；先验无法创造测量未区分的信息。

## 4. U-Net 与公平对照

复用 `functions/addip/model.py` 的 `ProPtyUNet` 主干，只替换输出头；不修改原有单波长实现。

- tau=softplus(raw_tau)，保证被动样品振幅 0<A<=1。
- d=opd_scale_um*raw_opd，输出具有长度单位。
- 输入为训练扫描的混合强度堆栈，按一个训练集最大值缩放并填充；物理损失仍使用原绝对强度。留出图不进入输入或归一化。
- 所有方法初值相同：A=exp(-0.1)、相位=0。网络输出头权重为零、偏置设为相应常数；第一步主干梯度为零是预期行为，输出头先更新后主干开始学习。
- BatchNorm 保持拟合模式；评价不切换 running statistics，避免改变 DIP 输出。
- 损失为 mean((sqrt(I_pred+eps)-sqrt(y+eps))^2)/mean(y)。可选 TV 在同一几何区域、相同物理输出域按通道平均；默认 TV=0。

| 比较 | 主要检验因素 |
|---|---|
| pixel_coupled vs pixel_independent | 物理参数化 |
| unet_coupled vs pixel_coupled | 同物理约束下的网络表示 |
| unet_coupled vs unet_independent | 网络内部的物理关联 |

像素和网络使用各自学习率，全部保存；等迭代数不是等计算量。报告参数量和含评价的耗时，但未证明每个基线已充分调参，也未加入传统 PIM/ePIE 基线。

## 5. 真值、数据划分与评价

| 场景 | 真值与目的 |
|---|---|
| shared_complex | 相同复物体；人工代码控制，接近旧 MATLAB 假设 |
| shared_opd | 共同 OPD 与吸收；基本物理关联验证 |
| spectral_absorption | 共同 OPD、波长独有吸收标记；默认任务 |
| dispersive | 上述吸收加 d_l=d0+((lambda0/lambda_l)^2-1)*d1；共同 OPD 失配压力测试 |

扫描为整数像素抖动栅格，不支持连续位置优化。扫描、噪声、网络种子分别保存；解析物体本身固定，改变扫描种子不等于测试新物体。

默认训练／留出为 20／5 个位置。ROI 由训练位置已知照明累积超过峰值 20% 定义，不靠物体真值选区。评价均在更新后解码，保存最终迭代；不根据真值或留出误差挑选最佳迭代。

1. 训练／留出观测和干净数据的混合振幅 NRMSE。
2. 每波长振幅 RMSE、去全局相位后的复场相对误差及 wrapped phase RMSE；不拟合幅值。
3. 有效 OPD 去常数偏置后的 RMSE；每通道单独去偏置，只评价空间变化，不宣称恢复绝对通道相位。
4. 吸收标记传递矩阵：将重建 tau 对常数、共同吸收纹理及所有波长标记联合回归。行是重建通道、列是真值标记，理想为单位矩阵。须同时看对角线增益、非对角泄漏及距单位矩阵误差；把全部标记抹掉不算抑制串扰。

标记回归是人工样品诊断，不是通用串扰指标；其真值基底仅用于评价，不参与训练。接近波长、极弱通道、少扫描等情况可能仍不可辨识。

## 6. 已核查文献与研究判断

| 文献 | 核查证据／角色 | 支持范围 |
|---|---|---|
| [Matsushima & Shimobaba, 2009, Optics Express](https://pubmed.ncbi.nlm.nih.gov/19997186/) | 论文摘要；传播依据 | 角谱法也有传递函数采样问题，需要带限 |
| [潘安等，2016，物理学报](https://www.cpsjournals.cn/article/doi/10.7498/aps.65.124201) | 出版社摘要；直接先例 | 多波长同时照明及光谱响应、探针、光谱比例恢复已有研究 |
| [Du et al., 2021, JSR](https://journals.iucr.org/s/issues/2021/04/00/gb5118/) | 已核查论文页面；相邻方法 | DIP 缓解多切片串扰有实验依据，但不能直接推出多波长分离有效 |
| [Lin et al., 2025, Nature Communications](https://www.nature.com/articles/s41467-025-61339-3) | 开放正文引言与方法；边界依据 | 色散样品和结构化照明已有研究，其卷积／联合去卷积路线不同于本共同 OPD 参数化 |

网络头、样品、诊断和协议是本项目工程选择，不是上述文献已证明的结论。潜在贡献“物理关联先验改善弱通道且保留真实光谱差异”目前属于推断和待验证实验，创新性未确立。

当前为 `pilot-ready`。继续条件：跨场景、噪声、光谱比例、初始化均有稳定收益且保留标记对角线。收缩或停止条件：优势在同物理约束的像素 AD 对照中消失，或共享先验抹去真实差异。扩大到盲重建与真实材料前需另行验证。
