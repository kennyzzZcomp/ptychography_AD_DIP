# 当前主线：共享纯振幅 USAF

## 模型

对两波长透射振幅近似一致的零相位薄样品：

```text
O_l(x,y) = A(x,y), 0 <= A <= 1, Im(O_l) = 0
I_j = sum_l w_l |D_l[P_l * S_j(A)]|^2
```

零相位与跨波长振幅相同是两项分别需要满足的假设。这里作为仿真先验直接成立；真实 USAF 镀层的波长响应需要实验核实。样品零相位不意味着探针零相位。

## 参数化

pixel_shared_amp 直接优化一个 M×M 实矩阵，经过 sigmoid 得到 A。
unet_shared_amp 复用原 ProPtyUNet 主干，仅保留单通道振幅头，经过 sigmoid 得到 A；相位头已从模块中删除，没有隐藏的可训练相位。

内部为兼容传播器，将同一张 A 扩展到 L 个波长，组合为 A+0i。扩展并未增加物体自由度。所有传播路径的梯度回到同一个 A。

两组初始振幅均为 exp(-0.1)，初始化物体相位严格为零。网络输出头初始权重为零，主干在输出头首次更新后获得梯度。可选 TV 直接作用于单张 A，不随波长数量重复计权。

## 真值

加载项目根目录 USAF.jpg（可通过 --usaf-path 改变）。灰度值除以 255 后直接解释为振幅，不取平方根，也不声称它是实测透过率标定图。保持长宽比例，采用 BOX 下采样，居中置于 A=1 背景中；图像和两波长物体均为零相位。

文件路径、SHA-256、灰度解释和下采样方式进入 config.json。细小条纹可能在真值下采样时已经消失，因此本版不自动给出 USAF group/element 或 lp/mm 分辨率。精确分辨率实验应换成指定线宽的高分辨率图案及足够细的物面网格。

## 传播和噪声

延用已验证的共同网格角谱算子：单位转换后按各自波长构建传播函数，裁片乘复探针、零填充、FFT 传播、裁取同一探测器窗口，再相加强度。带限约束控制传递函数频率采样；每次运行通过 padding 加倍检查窗口稳定性。固定 w，不执行动态光谱权重调度。

探针每个波长归一化 sum(|P_l|^2)=1，w 和为 1。每位置统一入射光子数 N，观测为 Poisson(N*I)/N；不逐帧归一化。单波长对照设 w=1，保持 N 相同。像素面积积分、背景、读出噪声和实验标定误差尚未模拟。

## 评价与比较

数据项为归一化振幅平方误差。训练／留出划分不变；网络只看训练测量。保存最终更新后的图像，不用真值挑选迭代。

重点评价一个共同物体：振幅 RMSE、相对误差、峰值按 1 固定的 PSNR、亮暗真值区域平均振幅的 Michelson 对比度、中心行剖面。无振幅重标定，也不做光谱串扰指标。亮暗区域以真值 A>=0.9 和 A<=0.1 选择，仅用于评价；区域对比度不能代替条纹分辨率。

原有复场与 OPD 文件字段为兼容格式保留；新方案的 OPD/虚部严格为零，不是成功估计了未知相位。测试还检查物体在所有波长上一致且训练后仍保持一致。

当前研究问题是同样的纯振幅共享约束下，U-Net 相比像素优化是否改善噪声鲁棒性和细节；以及同入射光子预算下双波长是否优于单波长。等迭代数不等于等计算量，需要后续调参和多种子验证。探针目前已知，不宣称盲重建能力。
