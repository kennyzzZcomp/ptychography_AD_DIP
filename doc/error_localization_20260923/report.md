# 已有 NPZ 的有限误差定位

## 决策摘要

此次没有运行训练或重建，没有修改求解器或输入 NPZ。
40% 无 TGV 的大误差与较低累计照明相关，但并非只在弱照明处出错。
TGV 在四个照明分组中均大幅降低误差，不能据此说它专门补偿弱照明。
留出空间块的周期模板预测没有获得正收益：当前不能把失败归因为主导性的扫描周期假解。
建议收窄表述为“当前场景中，低重叠恢复存在空间不均匀误差，振幅 TGV 的组合收益明确，具体机制尚未确定”。
本轮两项诊断到此结束，不自动加实验或新方法。

## 1. 累计照明与误差

误差为全局复数对齐后的复数残差；相关系数针对累计照明与残差模平方。
每个文件按自身照明排序，四等分，每组 2304 像素；跨 step 的分组不是同一组像素。
同 step 的 (4)/(5)/(10) 分组相同。

|文件 / 条件|振幅 PSNR|照明–误差 Spearman|最弱25%像素占总误差能量|最弱/最强组复数 RMSE|
|---|---:|---:|---:|---:|
|(4) 40%, 无TGV, .005/.02|9.60|−0.329|42.8%|0.507 / 0.278|
|(5) 40%, TGV .1, .005/.02|26.54|−0.119|39.7%|0.0545 / 0.0311|
|(10) 40%, 无TGV, .002/.01|10.98|−0.392|46.6%|0.470 / 0.236|
|(8) 60%, 无TGV, .002/.01|37.78|+0.044|24.4%|0.0134 / 0.0139|

四组 ROI 均没有完全未照明的像素，所以不是评价到了“完全没测到的区域”。
40% 无TGV 的负相关在真值暗/亮区域，以及低/高振幅梯度区域内仍存在：
(4) 分层相关约 −0.299 至 −0.346；(10) 约 −0.380 至 −0.417。
这降低了单纯由 USAF 黑白区域混合造成总体相关的可能，但不消除空间位置、相位结构等混杂。
不报告像素独立假设下的显著性 p 值。

同学习率 TGV 对照 (4)→(5)，从最弱到最强照明组的复数 RMSE：

- 0.5068 → 0.0545
- 0.3811 → 0.0450
- 0.3483 → 0.0392
- 0.2778 → 0.0311

各组均下降约 88%–89%，而不是只修复最弱一组。
最弱组仍占约40%的剩余误差能量。因此“相关性变弱”不等于照明不均匀已经被消除，
也不能据此设计并宣称照明自适应 TGV 必然更好。

## 2. 扫描周期相关残差

检查 q=(对齐重建−GT)/GT，按 (y mod d,x mod d) 拟合周期复数模板；
使用 |GT|² 加权，使预测误差对应物体复数残差能量。
将 d×d 空间块按棋盘分两折，每次仅在另一折拟合，在留出块计分。
指标为 1−周期模板留出误差/训练折常数模型留出误差。
正值代表优于常数；负值代表不能泛化，不能解读成“负的周期成分”。
常数模型和模板均只在训练折拟合。全局对齐沿用官方全 ROI 口径，不把这个分数当独立泛化性能。
同时检查加性残差及 GT 振幅模板，防止把样品自身纹理直接认成算法伪影。

|文件|d−2 比值残差得分|真实步长 d 得分|d+2 得分|
|---|---:|---:|---:|
|(4), d=35|−0.176|−0.221|−0.363|
|(5), d=35|−0.432|−0.455|−0.485|
|(10), d=35|−0.118|−0.091|−0.241|
|(8), d=24|−0.075|−0.045|−0.120|

加性残差得分也全部为负；GT 振幅控制也未得到正收益。
35像素周期每个被评分余类每折最少只有2个训练像素，24像素周期最少8个；全部9216像素均可评分。
不同候选周期的分块、模型自由度和样本数不同，邻近周期只作描述性控制，不能当严格显著性检验。

结论是“这项有限检查未发现可跨空间块预测的周期模板”，不是“数学上不存在 raster 歧义”。
ROI 在 d=35 时每轴不足3个周期，统计能力有限；非周期误差也可能掩盖较弱周期成分。
不利用拟合模板校正重建、提高正式 PSNR 或宣称证明了物体—探针串扰。

## 边界与停止

有证据：无TGV的40%误差在弱照明区更重；已有同配置TGV对照在各照明组均明显改善。
无证据：弱照明是唯一原因、周期歧义主导失败、TGV专门消除了串扰。
这里只定位最终物体误差，没有分析训练中间态，也没有对探针误差建立因果模型。
只有单场景、单seed、保存的最终数组；不把9216像素当成9216次独立实验。

按事先约定停止本轮，不追加模型或参数扫描。
研究决策：保留组合收益结果，收窄机制主张；本轮证据不足以启动针对性新算法设计。
