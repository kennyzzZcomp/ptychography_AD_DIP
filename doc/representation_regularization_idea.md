# 表示与正则化互补性：候选 idea 与有限验证计划

2026-09-23；使用 shushu-novelty-finder。仅研究设计，未修改求解器、未执行训练。

## 范围

对象：ProPtyNet_paper 的无预训练 U-Net 物体表示、像素探针联合恢复、物体振幅 TGV。
固定当前40%场景作为pilot；不展开弱照明、跳步、局部TGV、phaseTGV或网络替换。
目标不是再证明“网络＋正则化有效”，而是辨别组合收益的阶段依赖。
当前证据：同学习率U-Net无TGV9.60dB、有TGV26.54dB；低学习率无TGV10.98dB。
这支持组合效果，尚不证明持续互补、唯一机制、普适优势或文献新颖性。

## 三个候选，只推荐中间一项进入pilot

### A. 安全、弱创新：固定场景四组互补性评测

主张：U-Net＋TGV在当前条件优于U-Net、AD、AD＋TGV。
证据是已有结果；差异为本项目特定盲恢复设定，不是新算法。
最小验证：统一ROI/场景/支撑，并说明各表示的优化预算和学习率；已有四组尽量复用。
基线就是四组；不要求不同参数空间机械使用同一学习率。
可行性高、证据中等、风险低、影响窄，适合实验报告；不能单凭四柱状图证明协同机制。
停止：公平口径下优势消失则修正；不无限调参维持排名。

### B. 推荐、中等潜力：同状态撤除，区分“帮助到达”与“持续维持”

论文问题：低重叠盲恢复中，神经参数化和振幅先验的作用是否依赖优化阶段？
候选贡献：基于同一物体—探针状态的干预式比较，分离从头优化的到达能力与后续维持能力。
不是重新命名“warm start”为新算法；网络转换同时改变优化几何，结论必须限定为整个参数化/优化路径。
最近先例是DIP＋TV、VDIP-TGV与PtyINR；本轮尚未核实有无完全相同协议，故创新等级只是潜力。
现有终点对照只提供动机，并未验证该假设。
可行性中高、机制证据弱、风险中等；适合分析型pilot。严格控制切换状态和优化器重置比新增loss更重要。

#### Thesis Card

待检验命题：组合从头成功，不一定意味着两种约束在到达同一状态后都必须持续存在。
新意候选是实证分离这种阶段作用，而非一般性“隐式与显式先验互补”。
支持证据：同状态分支显示可重复、超过切换瞬态的分化。
反证/收窄：所有分支都保持并改进，说明至少从该状态继续时不必持续组合；或分化由优化器重置/更新幅度解释。

#### Experiment Card（提案，需确认后才实现）

固定40%场景、seed0、support1、eval96、同数据/目标/传播/探针更新规则。
共享U-Net＋TGV .1前缀固定1000步，不按GT挑选最好时刻；该点只代表中途状态，不预称“已进入正确吸引域”。
从同一严格同步的 O、P 状态分四支，每支固定1000步：

|分支|物体参数化|振幅TGV|
|---|---|---|
|A|保留U-Net|.1|
|B|保留U-Net|0|
|C|转换成像素变量，起始复物体精确相等|.1|
|D|转换成像素变量，起始复物体精确相等|0|

探针仍然未知且继续优化，不加入known-probe实验。阶段一成本共享计入，不宣称加速。
所有分支重置Adam状态，TGV分支复制同一辅助变量并一致处理其优化器；
额外保留一条不重置A续跑作重置控制（可与共享前缀正常续跑合并）。
总预算：1000共享前缀＋5×1000续跑＝6000步，不是五次独立完整训练；不同表示步耗时不同，记录真实耗时。
网络和像素变量不能共享同一个数值学习率当作公平性；先用各自既有配置，不搜索；
报告切换后的物体/探针相对更新幅度，出现明显数值爆炸时判定该比较不可解释，不将其包装为机制。
预先拒绝宽参数扫描；若需要额外步长匹配，只能作为下一轮经确认的有限控制。

指标：固定ROI振幅/相位指标、物体/探针复误差、数据项、TGV项、耗时、初始更新幅度。
分支起点须数值核验相同O/P、数据loss；保存更新后同步状态，避免旧输出与新探针混用。
不比较含不同正则项的total loss大小。GT只评价，不控制切换点或选择分支。
差异阈值作为pilot实用判据：末200步平均物体复误差相对A差至少20%，且不是只发生在重置瞬间；
探针指标与data项用来解释，不以物体PSNR单指标证明物体—探针机制。
单seed不做显著性结论。没有清楚分化就结束此pilot，不换切换点直到“成功”。

解释规则：B保持只支持该状态后TGV可撤除；C保持只支持该状态后不必继续网络参数化；
仅A保持提示持续组合可能重要，仍需排除优化器/步长混杂；都失败或A重置失败则先判协议有问题。
初次pilot不够支撑论文；若结果值得继续，再单独确认一个独立物体/初始化的复核，不现在承诺大规模扫描。

当前NPZ只有数组与历史，没有网络checkpoint，不能从现有最终NPZ恢复U-Net继续训练。
需要先增加checkpoint与分支入口并由用户在Colab跑；本轮没有写这些功能，也不给不存在的CLI命令。

#### 审稿人反对意见

1. “只是初始化效应”——这正是要区分的解释，若支持则如实报告，不强称表示约束必需。
2. “像素分支学习率不合适”——成立的威胁；发散不能作为支持机制的证据。
3. “一张USAF和一个seed不够”——pilot承认；正式分析需独立复核，不以9216像素代替重复实验。
4. “已有方法组合”——不主张组合创新，贡献取决于是否发现可复核且有实际意义的阶段作用。

判断：pilot-ready。潜在接收理由是同状态干预超出简单终点消融；潜在拒绝理由是既有DIP优化现象的窄应用且混杂未排除。
失败退路：保留组合收益与负结果，形成技术报告，不继续堆模块。

### C. 高风险、强创新目标但尚未成立：证据驱动的表示退出策略

仅当B显示不必始终维持网络/TGV且有可复核信号时，研究不依赖GT的退出规则。
机制候选是依据恢复状态决定是否保留表示/正则化，不是按迭代数拍一个调度。
目前无可靠触发量，也未穷尽DIP早停、warm-start、自动正则化文献，不能称强创新已成立。
最低验证：与固定U-Net＋TGV、固定时刻退出、始终像素＋TGV比较同预算和质量；
如果不能超过固定时刻规则，或只用GT挑点才能成功，就终止。
可行性低至中、风险高、证据弱；只留作条件式后续，不进入实现、不视作本轮第二个研究分支。

## Claim–Evidence map / 最终选择

- “组合有用”：本项目配对结果支持，仅限已测场景。
- “组合本身新”：文献反证，不主张。
- “需要一直组合”：现有终点结果不足，候选B检验。
- “阶段性退出更好”：尚无证据，不启动候选C。

选择B；A作为现有证据基础，C作为有证据后的可能延伸。
本轮检索和设计结束。新增Colab实验和checkpoint实现等待用户确认，不自动运行。
