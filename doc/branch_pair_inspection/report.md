## 振幅SSIM下降发生在哪里

使用原SSIM的7×7窗口，在去除3像素边界后的8100个窗口中心比较。
GT局部方差<1e-6定义近常量窗口（1794个），其余6306个定义结构窗口；
两个分支共用同一GT分组，不由重建结果挑区域。

|局部诊断|A|B|
|---|---:|---:|
|近常量窗口平均SSIM|.701|.113|
|结构窗口平均SSIM|.715|.796|
|近常量窗口中心振幅RMSE|.0433|.0824|
|结构窗口中心振幅RMSE|.1753|.1352|

近常量区像素误差在B更大，结构区则更小。按窗口数加权的SSIM变化中，平坦区贡献约−.130，结构区补回约+.063，净−.067。
这解释整体SSIM下降与PSNR提高的共存；不是指标计算bug，也不是B全面胜出。
图中A目标偏平滑/模糊，B目标更清晰但振幅背景有辐条状伪影；该形状与GT相位的辐条结构相似。
只能说与振幅/相位混入的解释相容，不据此宣称已经证明串扰机制。

## 研究结论与边界

对本场景、这个共享状态、重置Adam的后半程，固定TGV .1在背景伪影抑制与结构/相位恢复间呈现取舍。
相较于仅看汇总表，应将“撤除TGV更好”修正为“多数全局误差改善，但背景振幅结构保真变差”。
支持的是阶段依赖研究动机，不证明前期TGV必需、最优切换点、较小非零TGV必然更优或网络无法被其它优化器替代。
本次只分析已有数组，没有训练、改loss、重新调参或用额外对齐提高正式结果。
