# 传统 AD ptychography 仿真实验计划

目的：把「无正则、自由探针、MSE 数据项」的标准 AD 重建在**剂量、重叠率、探针未知度、
位置误差**四个轴上标定清楚，作为后续所有论断（TGV 何时有用、光瞳参数化值不值）的对照系。

现状问题不是缺实验，是**已有的实验彼此不可比**：条件不同、n=1、stage 数各异。
这份计划的一半工作量在补方法学，另一半才是新数据。

## 2. 先补方法学（不做这一步，后面全部白做）

### E0 — 确定性检查（10 分钟，最高优先级）

同一配置连跑两次，检查权重是否逐位相同。

- `shuffle=False`、`batch_size=1`、初值确定（物体全 1、探针解析生成），
  **无噪声且 `SCAN_SEED` 固定时，训练原则上是完全确定的**。
- 若确实逐位相同 → 无噪声条件下 n=1 就是精确值，不需要重复实验。
- 若不同 → TF 的并行归约存在浮点非确定性，**所有 n=1 的结论都要重新评估**。

先做这个，因为它决定后面每个实验要跑几次。

### E1 — 收敛判据（替换掉「跑 8 个 stage」这种随意设定）

基线配置跑 **24 stage**，逐 stage 记录物体复场误差与探针误差。

判读：
- 找到误差改善 < 0.5%/stage 的 stage 数，记为 `S*`
- 之后所有实验用 `S = S*`，并在报告里写明
- 若 24 stage 仍在明显下降 → 现在所有「A 比 B 好」的结论都可能只是
  **A 收敛更快**，不是 A 更好。这是目前最大的解释风险。

同时输出 lr 衰减后的有效步长曲线（`lr·decay^st`），确认末期不是因为 lr 太小而假性收敛。

### E2 — 学习率的公平性

已有的 lr 是在**无噪声、53.6% 重叠**下调的。低剂量和低重叠下最优 lr 未必相同，
沿用同一个值等于让困难条件带伤上场。

做法：在**最难**的一档（最低剂量 + 最低重叠）重扫 `lr_OBJ, lr_PRB ∈ {1e-2, 3e-2, 1e-1}`。
- 若最优仍是 3e-2 → 固定它，后续实验不再扫 lr
- 若变了 → 后续每个条件都要用「各自的最优 lr」，否则测的是调参不是方法

### E3 — 指标统一

现在代码里 `evaluate_object_roi`（先裁后对齐）和 `ic.evaluate_object`（先对齐后裁）
并存，Phase 0 的 cell 里又自己算了一遍。**统一成一个函数**：

- 主指标：**ROI 内消去全局复因子后的复场相对误差**（`EVAL_CROP=16`）
- 次指标：幅值 SSIM / PSNR、相位 RMSE（仅在 `|O_gt| > 5%·max` 的区域）、探针复场误差
- 全部在同一 ROI、同一对齐方式下计算

## 3. 主实验矩阵

每个实验只动一个轴，其余按 §0 固定。若 E0 显示非确定，或该轴涉及随机性
（噪声、jitter），每档跑 **5 个种子**，报 **中位数 + IQR**。

### E4 — 剂量轴（核心）

`PEAK_PHOTONS ∈ {1e2, 3e2, 1e3, 3e3, 1e4, ∞(无噪声)}`，全局归一化，5 个噪声种子。

对每档同时报告**输入端的噪声水平**（幅值相对误差、零像素占比），
这样横轴才有物理意义而不只是一个旋钮读数。已知 1e3 → 幅值误差约 12%。

预期与判读：
- 画「输入噪声 → 输出误差」的传递曲线。斜率若接近 1，说明重建没有任何降噪能力，
  这正是正则化应当介入的地方 —— **TGV 实验的立足点就在这条曲线上**
- 找到误差开始急剧上升的**拐点剂量**，后续所有正则/参数化实验就在拐点附近做

### E5 — 重叠率轴（核心）

固定视场 ~128 px，`(k×k, step)` 取 `(4,26.7) (5,20) (6,16) (7,13.3) (8,11.4)`，
对应面积重叠 39.1 / 53.6 / 63.1 / 70.2 / 75.2%，5 个 jitter 种子（`SCAN_SEED`）。

**必须写进论文的混淆**：重叠率与测量冗余不可分离，点数从 64 降到 16 时
每像素被照亮次数同时从 7.37 降到 1.86。真实实验中这两者本来就绑定，
所以这个混淆是诚实的，但要说清楚，不能只说「低重叠」。

判读：找到误差急剧上升的**临界重叠率**。文献常引 60%，这里能不能复现出来。

### E6 — 剂量 × 重叠（2D，可选但价值最高）

E4 与 E5 的 3×3 子集（低/中/高各取一档）。目的是看两者是**相加**还是**相乘**：
若低剂量下的临界重叠率明显高于高剂量下的，说明二者耦合，
后续任何单轴结论都必须注明另一轴的取值。

### E7 — 探针未知度轴

| 档 | 设置 |
|---|---|
| 探针已知 | 探针固定为真值，只解物体（`PRB_epoch=0`） |
| 探针近似已知 | `z_probe_init` 误差 0% / 10% / 30% |
| 探针未知 | `PROBE_INIT='flat'` |

这一轴给出「联合求解探针要付多少代价」。参数化路线已放弃，所以这一轴现在的用途是：
给低剂量/低重叠实验定一个上界（探针已知 = 只解物体），说明还有多少损失是探针带来的。

### E8 — 位置误差轴

给 `input1` 的位置加高斯扰动 σ ∈ {0, 0.1, 0.25, 0.5, 1.0} px，但**模型仍用标称位置**
（即位置误差不被建模）。已知取整引入的 0.235 px 平均误差就让 SSIM 从 0.909 掉到 0.731，
所以这个轴很陡，值得单独标定。

## 4. 报告格式（每个实验统一）

1. 条件表（把 §0 抄一遍，标出被改的那一项）
2. 主指标 vs 轴变量的曲线，中位数 + IQR 带
3. 逐 stage 收敛曲线（至少最难和最易两档）
4. 重建图像条：最易 / 拐点 / 最难 / ground truth
5. 一句话判读，以及**判读规则要事先写死**：
   差异必须超过 **2× 种子间 IQR** 才算真实差异，否则记为「无差异」

## 5. 预算

本机 CPU 实测：25 点 × 8 stage ≈ 35 s/run。

| 实验 | run 数 | 估时 |
|---|---|---|
| E0 确定性 | 2 | 2 min |
| E1 收敛（24 stage） | 3 | 6 min |
| E2 lr 公平性 | 9 | 6 min |
| E4 剂量 | 6×5 = 30 | 20 min |
| E5 重叠 | 5×5 = 25 | 18 min |
| E6 剂量×重叠 | 9×5 = 45 | 30 min |
| E7 探针未知度 | 5×5 = 25 | 18 min |
| E8 位置误差 | 5×5 = 25 | 18 min |
| **合计** | ~164 | **~2 小时** |

若 E1 把 `S*` 定到 16 stage，整体翻倍到 4 小时。仍然完全可跑，
**没有理由继续用 n=1 的单次结果下结论**。

## 6. 执行顺序

```
E0 确定性  ──→ 决定要不要重复实验
   ↓
E1 收敛    ──→ 定 S*，此后所有实验用它
   ↓
E3 指标统一 ─→ 改代码，一次性
   ↓
E2 lr 公平性 ─→ 定 lr 策略
   ↓
E4 剂量 ─┬─ E5 重叠 ─┬─ E6 2D
         └─ E7 探针  └─ E8 位置
```

前四步是**地基**，加起来不到 15 分钟，但决定了后面 2 小时的数据算不算数。

## 7. 这份计划不包含的东西

- **与迭代法（ePIE/rPIE/DM）的对比**：要写论文的话这是必须的，但需要另外实现一套，
  工作量与上面整个计划相当。建议单列。
- **多探针模式（mixed states）**：部分相干下的标准做法，当前前向模型是单模的。
- **位置精修（position refinement）**：E8 只测「位置错了有多糟」，不测「能不能修好」。
- **实验数据**：全部是仿真。仿真结论迁移到实测通常会打折，要在论文里说明。
