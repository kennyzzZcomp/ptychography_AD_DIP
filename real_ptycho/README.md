## 固定配置

| 项目 | 本实验设置 |
|---|---|
| 原数据 | `ptychogramx`: 225×2000×2000 强度；`positionx`: 2×225，单位 mm |
| 选帧 | 按实际坐标恢复15×15栅格，在四个中心候选10×10块中选择物理中心最近者 |
| 本数据选中范围 | 原栅格第4–13行、第4–13列（从1编号）；15取10不存在唯一对称中心块 |
| ABCD | 所选10×10的行列奇偶分组，每组25张；保留原帧编号和实际坐标抖动 |
| 光学参数 | λ=632.8 nm；样品到感光面 z=6 mm；探测器像元3.76 μm |
| 坐标轴 | 默认 `positionx[0]→y`、`positionx[1]→x`，这是待核实的映射假设 |
| 前向 | 双线性取物体局部场 × 探针 → 中心化、正交归一化二维 FFT → 模长 |
| 采样 | 原生N=2000；物面像元 λz/(NΔd)=0.504894 μm；物体画布2520×2520 |
| 探针 | 自由复数像素；两个阶段均优化；跨阶段保留探针及其 Adam 状态 |
| 第一阶段 | 共享 U-Net16，保留内部 concat；每次更新一组，ABCD依次轮换；500次=125轮 |
| 第二阶段 | 新 U-Net32，保留内部 concat；`O = O1 + Δreal + iΔimag`；零残差初值；每次更新使用全部100张 |
| 学习率 | 两阶段网络0.0005、探针0.01 |
| 第一阶段 TGV | 振幅TGV权重0.01；α0=2、α1=1、ε=0.001；辅助场Adam每次5步、学习率0.01 |
| 第二阶段正则 | **TGV=0；只有覆盖加权复数 NLM 约束** |
| NLM | patch=3，search radius=7，h=0.8σ；σ由O1局部差分MAD估计；每25步刷新目标 |
| NLM强度 | 起始时令正则梯度范数/数据梯度范数=0.5，计算一次λ后固定；**不是直接λ=0.5** |
| 网络输入 | S1：该组25张强度图分别按最大值归一化后居中补零；S2：固定O1振幅、cos相位、sin相位 |
| 损失 | `mean((q·abs(FFT(P·Opatch)) − sqrt(I))²)`；每次更新只拟合一个整体幅度增益q |

强度预处理只除以全部100张的一个共同平均值，保留各帧之间的相对强度；**不另加噪声，不自动扣背景，不进行逐帧曝光归一化**。网络输入的逐通道归一化不改变用于物理损失的测量。

### 与仿真接口不同、必须说明的适配

- **探针初值不是全1**：使用平均测量振幅的零傅里叶相位逆FFT，随后归一化。纯夫琅禾费下，全1物体＋全1探针会产生单点傅里叶谱，存在零频以外梯度退化问题。这里的探针初始化只是数据驱动启发式，不代表真实探针已知。
- 未知真实照明直径，不能沿用仿真的已知圆盘支撑。S1 TGV及四组输出融合使用**计算窗口覆盖并集**，不是测得的照明范围。NLM覆盖权重由S1恢复探针的强度累积估计并固定，亦不是GT。
- 坐标不取整：保留毫米坐标，并按物面像元换算，使用双线性插值。去掉共同平移仅改变画布原点。
- 为限制显存，网络使用activation checkpoint，传播按帧分块。第一遍计算**所有相关帧共用**的最优增益q，第二遍累积物体/探针梯度，最后只执行**一次**optimizer更新。不是每帧各更新一次，也不是每块单独拟合q。会增加计算时间，不能与旧仿真计时直接对比。
- BatchNorm仍用原训练模式；checkpoint重计算和评估读出不会额外改变BN统计量。数学梯度一致性已有小尺寸单元测试，不能据此保证不同GPU逐位一致。

## 输出看什么

| 文件 | 内容 |
|---|---|
| `config.json` | 所有配置、选帧、坐标、数据指纹、设备、实际NLM系数及假设 |
| `selected_frames.csv` | 100个位置对应的原始帧编号（0起）、行列及ABCD组 |
| `input_preview.png` | 所选栅格及平均衍射强度 |
| `stage1.npz` | 第一阶段复物体及探针 |
| `reconstruction.npz` | 两阶段物体、最终探针、坐标和配置，无GT字段 |
| `reconstruction.png` | S1/S2振幅、相位及最终探针，全画布显示 |
| `loss_curve.png/.pdf` | 横轴iteration，纵轴全部100张的相对振幅RMSE |
| `history.json`、`summary.json` | 测量误差及分阶段训练时间；不含评估、初始化和保存时间 |
| `stage1_weights.pt`、`stage2_weights.pt` | 网络权重、探针及探针Adam状态，供审计；不是完整断点续训文件 |
| `intensity_cache.npy` | 选中测量的磁盘缓存，原生约1.6 GB；结果保留时可单独移除缓存 |

真实数据没有GT，**不计算PSNR，也不把loss下降当作分辨率改善的证据**。正式结果需检查USAF条纹可分辨性、测量残差、探针形状，并与可靠的PtyLab重建核对。显示的振幅上限为各图99.5百分位，仅影响预览；NPZ保存未裁剪的数值，跨阶段振幅尺度也存在盲重建歧义。

## 仍需核实的实验条件

1. **“PtyLab使用Fraunhofer”不等于已证明6 mm传播满足该近似。** 当前按要求接入，未验证光路/原PtyLab配置；收敛不代表物理模型正确。
2. 3.76 μm假设2000×2000来自直接裁剪、没有binning或resize；两者若存在，需改有效像元尺寸。
3. 两行坐标与图像x/y方向、符号需核对。可显式用 `--position-order xy`、`--flip-x`、`--flip-y`，不要为得到好看的图隐式换轴。
4. 未知暗场、背景、饱和掩膜及相机增益；不把当前浮点强度当作已标定光子计数。未知探针直径，也不宣称这份数据的重叠率是80%。

### 显存与测试范围

默认原生2000²并不等于仿真的64/128。原生物体2520²、第一阶段输入25通道，占用明显更大。优先在L4等较大显存GPU运行；**尚未在L4验证原生完整500＋500是否可行，不承诺显存一定足够**。默认`--chunk 1`且开启checkpoint；OOM时会保留已生成文件并报错，不会悄悄降低分辨率。

`--detector-crop 512`等选项是明确的中心裁剪，**会丢掉外围测量、改变物面采样间隔和可用频率范围，不能视为原生2000²等价的省显存版本**。不要为了跑通默认使用它当正式结果。
